# 小猪搭手品牌资产

“暖科技任务猪”是当前确认的角色方向。小猪保留声账的粉红猪鼻、耳朵、温和表情和印章构图；任务轨道与薄荷绿信号光负责表达聆听、执行和接管状态。

## 文件

| 文件 | 用途 |
| --- | --- |
| `piggy-task-mark.svg` | 透明底主标记 |
| `app-icon.svg` | 1024 × 1024 不透明 App 图标 |
| `adaptive-icon.svg` | Android 自适应图标透明前景 |
| `monochrome-icon.svg` | Android 单色图标 |
| `brand-lockup.svg` | 横向品牌组合 |
| `state-sheet.svg` | 六种交互状态总览 |
| `tokens.json` | 颜色、圆角、动效与悬浮球参数 |
| `exports/` | Quick Look 导出的 PNG 预览 |

## 使用规则

- 主标记周围至少保留猪耳到外轨道之间同等宽度的空白。
- 小于 48px 时隐藏轨道刻度，只保留头部和信号弧。
- App 图标不使用文字，不直接套用户系统尚未提供的圆角蒙版。
- `Signal` 薄荷绿只表达活跃状态，不作为大面积背景或小字号正文。
- 状态动效必须可中断；禁止持续旋转和随机漂浮。
- 矢量源文件是事实来源，PNG 只用于预览和文档。

完整设计、唤醒和声音规则见 [角色、唤醒与声音设计](../../docs/13-brand-character-and-voice.md)。
