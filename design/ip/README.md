# 猪哥 IP 资产

“猪哥”是跨产品复用的角色 IP。系列产品采用一个母版角色，通过服装、道具和局部强调色形成产品变体。

## 版本

| 版本 | 内容 | 状态 |
| --- | --- | --- |
| v0.1 | 全身正面、四视图、八种表情、六种手势 | 当前身份母版 |
| v0.2 | 基于三张身份参考图的 Figma 精修候选 | 已停止，不作为最终方向 |
| v0.3 | 使用既有角色资产的高保真产品界面 | 当前视觉候选 |

## 规则

- 头部 App 图标继续使用 `design/brand/`。
- 全身和表演资产使用 `design/ip/`。
- 产品变体不得改变头型、五官间距、身体比例和尾巴信号灯。
- 3D 必须基于审核通过的 2D 四视图制作。

角色设定、产品变体和产权清单见 [猪哥角色 IP 圣经](../../docs/15-character-ip-bible.md)。
