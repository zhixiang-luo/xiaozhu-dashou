# 猪哥 IP v0.3

## 方向

回到已认可的角色本身，用高保真产品界面重新呈现 IP，而不是继续生成新的猪。

设计采用“暖色编辑部 × 深色任务界面”的对比：左侧展示猪哥作为手机里的任务搭档，右侧保留清醒的角色识别信息，并将第一版表情系统作为产品资产呈现。

## 文件

| 文件 | 用途 |
| --- | --- |
| `preview.html` | 可编辑的 1600×1000 高保真页面源文件 |
| `assets/` | 页面使用的既有角色、图标和表情导出 |
| `exports/hero-board-v2.png` | 3200×2000 主视觉导出 |
| `exports/hero-board-preview.png` | 1600×1000 快速预览 |

## 约束

- 角色主体直接使用 V0.1 全身图，未重画。
- App 图标直接使用现有猪哥头部标记。
- 表情区域直接使用维护者认可的 V0.1 八种表情。
- 不包含 Figma 文字生成试稿或任何其他猪角色。
- 本地页面不依赖外部字体、图片或网络资源。
