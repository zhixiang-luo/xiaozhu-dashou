# 小猪搭手 1.0 产品需求

> Status: Draft
> Owner: Product + Android
> Last reviewed: 2026-10-23

## 用户入口

- 主 App：权限引导、设备状态、App 白名单、任务历史和设置。
- 悬浮球：按住说话、点击开始/停止、展示任务进度、确认与接管。
- Developer Edition 支持常驻唤醒词、按住说话和文字输入。

## 核心用户故事

### P0-1 发起任务

用户按住悬浮球说出目标。App 转写为文字，展示识别结果并开始任务。用户可取消或编辑尚未执行的任务。

### P0-2 打开 App

用户说“打开网易云音乐”。助手通过精确包名或 Deep Link 启动，并验证前台 App。未安装或无法打开时给出明确提示。

### P0-3 微信回复

用户说“给张三说我在路上”或“回复他说晚点到”。

- 指定联系人：搜索唯一匹配后进入会话。
- 当前会话：仅操作当前前台微信会话。
- 普通低风险文本：直接输入并发送。
- 同名联系人、群聊、附件、链接、敏感文本或搜索异常：暂停要求选择或交还用户。
- 发送后必须观察会话，确认目标消息出现；无法验证时如实报告。

### P0-4 网易云音乐

- “暂停”“继续”“下一首”可通过系统媒体控制完成。
- “播放某首歌”打开网易云音乐，搜索、选择并播放。
- 歌曲不存在、版本歧义、未登录或出现付费/广告弹窗时停止并说明。

### P0-5 中断与接管

用户可随时停止任务。停止后，迟到的模型动作和排队动作必须失效。应用进入前台或用户取回 Shizuku 控制时，执行器停止注入。

## 自动执行策略

| 场景 | 默认行为 |
| --- | --- |
| 打开 App、普通导航、查询 | 自动执行 |
| 媒体暂停、继续、切歌 | 自动执行 |
| 唯一联系人、普通文本直接聊天 | 自动发送 |
| 微信同名联系人、结果不确定 | 暂停询问 |
| 群聊、附件、链接、支付相关内容 | 确认或阻止 |
| 付款、转账、红包、验证码、密码、银行卡 | 阻止自动执行，交还用户 |
| 删除、拉黑、举报、权限修改 | 人工处理 |

显式用户指令本身是该次动作的授权。安全判断不能仅依赖模型文本，必须结合 App、控件语义、目标确定性和本地规则。

### P0-6 连续上下文

- 监听通知、屏幕状态、前台 App 和剪贴板。
- 保存可检索的屏幕时间线和任务事件，用于回答“刚才”“昨天”等指代。
- 支持从历史界面、截图或通知中恢复目标信息。
- 账号、支付和验证码内容不得写入长期记忆。

### P0-7 跨 App 任务

- 支持从一个 App 提取信息并在另一个 App 中使用。
- 首组验收任务：从微信提取地址并在高德地图开始导航。
- 每一步验证目标 App 和页面，失败时暂停并允许接管。

### P1-1 个人记忆

- 记住联系人别名、常用路线、音乐偏好和重复任务。
- 记忆可查看、编辑和删除。
- 成功任务可转化为确定性技能。

## 功能边界

- Developer Edition 可以读取通知和保存屏幕上下文，但不绕过验证码、风控、支付安全页或 `FLAG_SECURE`。
- 不保证任意 App 可用；每新增 App 必须提供技能、选择器、验证方式和测试。
- 不提供 iOS 本机全局控制。Root 只在专用测试机上作为可选增强，不作为必需条件。
- 账号登录、支付、验证码、密码和生物识别始终由本人完成。

## 非功能要求

- 用户停止任务后，不允许再执行任何新动作。
- 所有模型动作经过共享 schema 校验和本地策略检查。
- 普通动作不弹出无意义确认；风险确认只在实际需要时出现。
- 任务日志可以保存完整上下文与截图，但凭据和支付信息除外。
- 任何界面变化导致目标不确定时，宁可暂停，不做猜测点击。

## 验收基线

- 应用启动和媒体控制至少 19/20 成功。
- 微信当前会话和指定联系人两条路径各至少 18/20 成功。
- 跨 App 地址到导航任务至少 17/20 成功。
- 未经授权的消息发送、错误联系人发送、支付执行和凭据进入长期记忆均为 0 次。
- Shizuku 断开、网络超时和用户取消均可安全结束。
- 真机验收设备和系统版本记录在 `docs/10-acceptance-record.md`。
