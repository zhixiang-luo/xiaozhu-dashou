# 安全与隐私

> Status: Draft
> Owner: Security
> Last reviewed: 2026-10-23

## 安全目标

小猪搭手 Developer Edition 明确接受个人数据收集和长期保存。安全目标不再是减少个人数据采集，而是防止危险错误和凭据泄漏。

- 不让错误收件人收到消息。
- 不让支付、验证码、密码和生物识别被模型自动操作。
- 不让屏幕提示词注入改变权限、审批和工具边界。
- 不让取消后的迟到动作继续执行。
- 不让密码、验证码和支付凭据进入长期记忆或调试日志。

## 威胁模型

| 威胁 | 示例 | 控制 |
| --- | --- | --- |
| 错误收件人 | 两个“张三”，搜索命中错误会话 | 唯一目标校验、同名暂停、发送前再次观察 |
| 凭据泄漏 | 截图含验证码、密码或支付凭据 | 安全页面暂停，凭据不写入长期记忆 |
| Prompt injection | 页面文字命令 Agent 读取其他 App | 屏幕内容标记不可信，本地策略不可被模型覆盖 |
| 迟到的动作 | 用户取消后模型返回旧点击 | 任务代次、动作 ID、执行时效和取消屏障 |
| 权限滥用 | 模型请求不支持的 App 或系统设置 | 包名白名单、动作白名单、人工审批 |
| 密钥泄漏 | API Key 打包进 APK 或写入日志 | 服务端环境密钥、客户端无供应商密钥 |
| 重放与越权 | 多设备盗用任务接口 | 设备身份、短期令牌、速率限制和会话绑定 |
| 依赖供应链 | 第三方库被劫持 | 锁文件、来源审查、依赖扫描和更新记录 |

## 数据分类

### 禁止自动操作或长期保存

- 密码、验证码、支付密码、银行卡完整信息；
- 身份证、护照、人脸等身份凭证；
- 银行、支付、证券安全界面中的敏感内容；
- 用户明确标记为私密或不允许采集的内容。

### 可采集但不自动执行

- 消息收件人、群聊身份和聊天上下文；
- 地址、手机号、订单号和位置；
- 文件、链接、摄像头/麦克风内容和剪贴板。

### Developer Edition 默认可长期保存

- 屏幕时间线、通知、联系人、剪贴板、任务轨迹和控件结构；
- 用于调试、记忆和技能学习的截图与模型观察。

## Developer Edition 数据策略

- 屏幕、通知和聊天上下文默认可发送到选定模型并写入个人记忆。
- 密码/OTP/支付凭据仍必须排除；无法判断时停止并请求用户。
- 截图和页面索引可用于调试、回放和技能学习。
- 凭据页面只能记录“已暂停”这一事件，不记录内容。

## 风险策略

风险判断综合：

1. 动作类型；
2. 是否产生外部副作用；
3. 是否不可逆；
4. 是否传输敏感信息；
5. 目标是否唯一确定；
6. 当前 App/页面是否符合预期。

普通消息在目标唯一时可自动发送。账号登录、支付、转账、红包、验证码、密码、生物识别和安全设置始终阻止自动执行。

## 身份与传输

- App 与云端使用 TLS/WSS。
- 使用设备注册后的短期令牌，令牌可撤销并绑定设备。
- API 请求设置大小、速率、超时和并发限制。
- 服务端密钥来自环境变量或密钥管理系统，不进入镜像、日志或客户端。
- 任务接口不接受未签名或过期动作。

## 日志与可观测性

- Developer Edition 可以记录截图、聊天上下文、联系人别名和语音原文，用于记忆、回放与评测。
- 记录任务 ID、动作类型、schema 校验结果、风险决定、错误码和耗时。
- 提供一键清空个人记忆和调试记录的操作。
- 生产指标按设备/版本聚合，便于定位失败。

## 发布门槛

- 所有高风险规则有自动化测试和真机测试。
- 日志和崩溃报告经过敏感字段扫描。
- 依赖锁定并通过漏洞扫描。
- 公开发布前完成 GitHub 私密漏洞报告、许可证和安全审查。
