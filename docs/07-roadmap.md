# 小猪搭手开发路线图

> Status: Draft
> Owner: Project Lead
> Last reviewed: 2026-10-23

## 里程碑

当前进度：M0、M1 完成；M2 的本地开发和 DeepSeek 规划链路可用；M3.5 的系统日历
增删改查与本地结构化背景记忆已完成 Redmi K60 真机验收。下一步优先稳定通用 Android
操作与技能框架；微信继续作为可选技能线，不阻塞主路线。

### M0 文档与契约冻结

交付：

- PRD、系统架构、Agent 协议、安全、测试和协作文档；
- 根目录与模块级 `AGENTS.md`；
- `packages/contracts` 的初始 schema 与测试向量；
- 模型供应商接入指南和兼容性矩阵模板。

退出条件：Android、服务端和模型负责人能够仅依赖仓库文档描述各自接口，共享概念没有冲突。项目正式名称、目标设备和默认模型路由已经确定。

### M1 Android 骨架与基础执行

交付：

- Kotlin App、悬浮球、按住说话、文字兜底；
- 权限引导、前台服务和任务状态界面；
- 无障碍观察、Shizuku 驱动和无障碍降级；
- 打开 App、取消、超时和资源清理。

退出条件：真机完成“打开指定 App 并停止”闭环；Shizuku 断开安全降级。

### M2 云端任务循环

交付：

- Fastify 服务、设备认证、WebSocket 事件；
- 共享 schema、任务状态机和 PostgreSQL 事件存储；
- OpenAI `gpt-6.1-sol` 规划与视觉 adapter，以及 `gpt-6-luna` 快速意图路由；
- 模型密钥、超时、重试、日志脱敏和成本限制。

退出条件：固定桌面型 UI 任务完成“观察—动作—验证”多次循环；取消后迟到动作被拒绝。

### M3 媒体能力

交付：

- 系统媒体控制；
- 网易云音乐技能；
- 搜索、播放和状态验证；
- 登录、广告、版权和歌曲歧义降级。

退出条件：媒体控制和指定歌曲场景达到验收基线。

### M3.5 系统日历与本地上下文

交付：

- 自然语言查询、创建、修改和删除唯一匹配的个人日程；
- CalendarContract 本地执行、操作前重查和操作后回读；
- 手机 SQLite 保存近期任务、联系人别名和偏好；
- `ContextBuilder` 注入未来日历、近期任务、当前页面和偏好；
- DeepSeek 使用结构化背景解析省略指代和“朱哥/猪哥”一类同音标题。

退出条件：真机完成日历查询、修改和删除验收；本地任务在 App 进程重启后仍存在。

### M4 微信回复

交付：

- 当前会话和用户明确指定联系人的显式回复；
- 唯一收件人判断、同名处理；
- 风险分级、自动发送、敏感内容阻止；
- 发送后消息气泡验证和脱敏审计。

退出条件：先完成“用户说帮我回才回”的当前会话路径；零错误收件人和零未授权发送后，
再开放白名单常驻自动回复。

### M4.1 连续上下文与个人记忆

交付：

- 通知与屏幕时间线；
- 剪贴板与历史页面索引；
- 任务记忆、别名和可删除的偏好；
- “刚才”“昨天那张截图”等上下文指代。

退出条件：至少 20 条历史指代测试中 18 条能定位到正确内容。

### M5 模型平台与团队协作

交付：

- 第二个模型供应商 adapter 或视觉定位 adapter；
- provider registry、路由、兼容性矩阵和模型对比报告；
- CODEOWNERS、正式 CI、发布流程和版本化配置；
- 新人按指南完成一次模型接入演练。

退出条件：新增模型不修改 Android 和通用任务协议，团队可以在独立目录并行开发。

### M5.1 跨 App Jarvis 任务

交付：

- 微信地址到高德导航；
- 通知到日历/提醒；
- 截图或文件到另一个 App 的受控传递；
- 长任务暂停、人工验证后继续。

退出条件：首组跨 App 任务达到验收基线，账号与支付步骤零自动执行。

### M6 开源候选版本

交付：

- 许可证、治理、安全披露、贡献流程和公开文档；
- 示例配置、演示数据、安装与真机验收说明；
- 密钥、个人数据、测试账号和内部路径清理；
- 可重复构建与版本发布说明。

退出条件：完成公开仓库安全检查，外部开发者能按 README 运行和验证。

## 跨里程碑规则

- 每次完成里程碑都更新本文件状态、README、`HANDOFF` 和验收记录。
- 里程碑范围变化先修订 PRD/ADR，再改实现。
- 模型和应用适配可以并行，但共享契约先合并。
- 没有测试和文档的能力不算完成。
