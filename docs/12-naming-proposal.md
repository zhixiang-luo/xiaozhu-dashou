# 产品命名提案

> Status: Draft
> Owner: Product
> Last reviewed: 2026-10-23

## 品牌参照

手机助手与“声账”共享粉红小猪角色和语音入口，但产品职责不同：

- 声账负责听见一句话并记好账。
- 本项目负责听见一句话并替用户操作手机。
- 小猪角色应温暖、克制、可信，不变成幼稚贴纸或夸张拟人。

最终名称不应直接使用“Jarvis”。可以参考语音助手的角色关系，但应形成独立品牌。

## 候选名称

| 名称 | 优点 | 风险 |
| --- | --- | --- |
| **小猪搭手** | 明确表达“帮你动手”，亲切但不过度卖萌 | 需要验证商标和域名 |
| **小猪随行** | 安静、日常、长期陪伴感强 | 行动感较弱 |
| **小猪应声** | 延续声音主题，突出响应 | 可能被理解为纯语音助手 |
| **小猪代劳** | 任务执行感强 | 更接近跑腿或代办服务 |
| **小猪在旁** | 亲近、轻量 | 产品功能表达不够直接 |

## 当前推荐

**小猪搭手**

推荐理由：

- “搭手”既有帮忙，也有实际执行的含义。
- 比“助手”更有产品识别度。
- 与声账的小猪角色共享性格，但不会混为同一个记账产品。
- 可以和声账形成：
  - 声账：听一句，记好账。
  - 小猪搭手：说一句，帮你做。

暂定品牌主张：

> 小猪搭手，你开口，我来做。

## 待维护者决定

- 从候选名称中确认正式名称。
- 做商标、应用商店重名和域名初筛。
- 确认与小猪角色的长期关系：共用角色、独立角色，或仅共享视觉语言。
- 确认英文名是否只用于代码仓库，还是需要公开面向用户。

## 改名影响清单

正式名称确定后，需要同步修改：

1. 根目录项目名和 Git 仓库名。
2. Android `app_name`、启动页和页面标题。
3. README、PRD、品牌宪章和路线图。
4. 模型 Prompt、服务名和日志前缀。
5. 文档目录和外部发布链接。

应用包名 `com.personaljarvis` 可暂不修改，避免开发期反复卸载和权限重置；公开发布前再统一决定正式包名。
