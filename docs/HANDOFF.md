## Open Risks

- 重装 Debug APK 会清除 Android 运行时日历权限并关闭无障碍服务，需要重新授权；
  这是首版原型尚待自动化的设备配置步骤。
- HyperOS 后台限制和 Shizuku 重启失效可能导致执行不稳定。
- 微信界面、输入控件和搜索结果会随版本变化。
- 消息自动发送必须实现严格的唯一收件人和敏感内容判断。
- 微信 8.0.79 的截图 OCR 会合并按钮、拆分消息并误识别标题；当前精确会话验证方案成本
  过高，暂不作为默认能力发布。
- 新的 Android 启动图标尚未经过目标真机桌面、深色主题、通知栏和小尺寸验证。
- “猪哥猪哥”包含重复音节，需要真实噪声环境下的误唤醒测试。
- 角色 IP 尚未建立完整创作档案、外部贡献者授权和著作权登记。
- 开源前需要完成许可证、安全披露和个人数据清理。
