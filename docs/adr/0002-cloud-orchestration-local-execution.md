# ADR-0002: 云端编排、本地执行

> Status: Accepted
> Date: 2026-10-23
> Owners: Architecture + Agent Runtime

## Context

通用任务需要较强模型和频繁版本迭代，但手机拥有敏感数据和实际操作权限。把全部能力放在任一侧都不可取：纯本地模型能力有限，云端直接操作设备会扩大隐私和权限风险。

## Decision

云端 Orchestrator 负责任务规划、模型路由、事件状态和 Prompt 管理；Android 负责采集、脱敏、风险判断、动作执行和结果验证。云端不直接调用手机注入接口。

## Consequences

- 模型与 Prompt 可以持续升级，App 不需要每次发版。
- API 密钥保存在服务端，客户端只保存短期设备令牌。
- 任务依赖网络；必须设计离线失败、超时和取消壁垒。
- 上传数据必须在本地最小化和脱敏。

## Alternatives Considered

- 完全手机直连模型：部署简单但密钥不安全、模型升级和团队协作困难。
- 云端浏览器/云手机执行：便于审计，但成本和延迟高，也不是用户本机助手。

## Migration / Follow-up

未来可以加入本地小模型或确定性技能作为云端降级，但本地策略和执行所有权保持不变。
