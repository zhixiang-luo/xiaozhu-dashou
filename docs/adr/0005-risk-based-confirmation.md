# ADR-0005: 风险分级确认

> Status: Accepted
> Date: 2026-10-23
> Owners: Product + Security

## Context

对每个动作都确认会让助手失去价值；完全不确认又可能导致错误收件人、误发消息或支付风险。用户明确说出的低风险任务本身已经是一种授权。

## Decision

根据动作副作用、可逆性、目标确定性、内容敏感性和当前页面状态分级：

- 低风险且目标唯一：直接执行。
- 有歧义或中风险：暂停、倒计时或一次确认。
- 支付、敏感信息、删除、账号和权限变化：阻止自动执行并交还用户。

普通低风险消息可在唯一联系人且内容正常时自动发送。

## Consequences

- 体验更接近真正助手，少一次无意义确认。
- 风险分类和唯一收件人判断成为关键安全能力。
- 模型置信度不能替代本地规则和执行前再次观察。
- 每条消息自动发送必须保留脱敏审计和错误上报能力。

## Alternatives Considered

- 每条外部消息都确认：安全但打断频繁，不符合产品目标。
- 除支付外全部自动：可能误发敏感内容或错误收件人，风险不可接受。

## Migration / Follow-up

V1 先对直接聊天普通文本启用自动发送。群聊、附件、链接和敏感文本先确认；只有在评测证明安全和稳定后才考虑扩大范围。
