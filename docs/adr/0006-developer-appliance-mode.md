# ADR-0006: Developer Appliance Mode

> Status: Accepted
> Date: 2026-10-23
> Owners: Product + Security

## Context

小猪搭手只运行在开发者专用手机上。用户接受屏幕、通知、联系人和任务上下文的长期保存，希望获得比消费级产品更完整的连续记忆和自动执行能力。

降低隐私限制不等于放弃错误防护。账号、支付、验证码和身份验证仍可能造成直接损失或凭据泄漏。

## Decision

引入 Developer Appliance Mode：

- 默认可采集和持久化屏幕、通知、剪贴板、联系人别名和任务轨迹；
- 普通私聊消息默认自动发送；
- 支持常驻唤醒词、连续上下文和跨 App 任务；
- 账号登录、支付、验证码、密码、生物识别和安全设置立即停止并交还用户；
- 敏感凭据不得进入模型上下文、长期记忆或日志；
- 用户可查看、清空和关闭个人记忆。

## Consequences

- Jarvis 能获得更完整上下文，行为和记忆更自然。
- 测试可以使用完整界面回放，提升技能稳定性。
- 任何凭据分类错误都可能带来较高影响，因此安全测试和人工接管必须优先。
- 未来面向普通用户时需要重新设计隐私模式，但可复用同一策略引擎和协议。

## Alternatives Considered

- 沿用普通消费级隐私限制：更安全，但无法实现用户希望的个人 Jarvis 体验。
- 完全不做安全限制：可能造成误付款、错误账号和凭据泄漏，不接受。

## Migration / Follow-up

当前只实现 Developer Appliance Mode。未来生产模式通过配置切换数据保留和自动执行策略，不修改通用任务协议。
