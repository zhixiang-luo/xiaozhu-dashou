# ADR-0008: Product Name 小猪搭手

> Status: Accepted
> Date: 2026-10-23
> Owners: Product

## Context

项目需要一个不与 Jarvis 品牌混淆、又能延续声账粉红小猪角色的正式名称。角色应温暖、克制、可信。

## Decision

正式产品名确定为 **小猪搭手**。

品牌主张为：

> 小猪搭手，你开口，我来做。

开发期 Android 显示名同步改为“小猪搭手”。`com.personaljarvis` 包名暂时保留，避免权限因反复重装而重置；公开版本发布前再决定正式包名。

## Consequences

- 产品和声账共享小猪角色，但职责和名称清晰区分。
- 当前 App 名称、文档和后续仓库名使用“小猪搭手”。
- 代码包名和内部 scope 暂时保留旧标识，发布前需要统一迁移。

## Alternatives Considered

- 贾维斯或小猪贾维斯：识别度来自他人品牌，不适合作为独立产品名。
- 小猪随行：陪伴感强，但执行含义弱。
- 小猪代劳：执行感强，但容易与代办服务混淆。
