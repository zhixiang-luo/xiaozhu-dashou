# v0.1.0 安全审查结论

> 审查日期：2026-10-23
> 范围：完整工作区
> 结论：允许以 Developer Edition Beta 公开源码；不宣称生产级自动发送

## 已检查

- 服务端 HTTP/WebSocket 设备 Token 与任务代次。
- DeepSeek Intent、SkillCatalog 和动作 Schema 校验。
- Shizuku `ProcessBuilder` 参数、包名校验和受控 App 重启。
- 前台 App 包名门禁、敏感页面分类和消息敏感词检查。
- 火山 PCM WebSocket 的鉴权、大小与时长限制。
- 调试截图/录音目录、Git 忽略规则和历史密钥扫描。
- GitHub Actions、Issue Forms、许可证和发布文件。

## 保留风险

### P2：微信固定坐标发送缺少会话标题验证

微信 8.0.79 不暴露可用 UI 树，当前“文件传输助手”流程使用校准坐标。虽然实现已经：

- 默认关闭 `ALLOW_WECHAT_AUTOSEND`；
- 发送前受控重启微信；
- 每次点击和输入前校验前台包名为 `com.tencent.mm`；
- 只支持文件传输助手，不自动发送到任意联系人；

但还没有在输入和发送前通过 OCR 验证顶部会话标题。因此，如果微信布局或会话入口变化，
仍存在落到其他会话的中等风险。

发布决定：保留为 Developer Edition Beta，README、安全文档和 Release Notes 必须明确
披露；在实现 `intended_conversation_visible` 与 `sent_message_visible` 的真实截图验证
之前，不得默认启用自动发送，不得宣传为生产级能力。

## 发布要求

- GitHub Private Vulnerability Reporting 开启后再公开。
- Release 不附带 Debug APK 作为生产安装包。
- 用户必须自行配置供应商 Key 和随机设备 Token。
