# App 技能模块规则

先阅读根目录 `AGENTS.md`、`docs/04-android-execution.md`、`docs/05-security-privacy.md` 和 `docs/guides/adding-app-skill.md`。

## 边界

- 每个技能只负责一个 App 或明确的一组流程。
- 技能不得包含模型 API Key、真实账号或未脱敏测试数据。
- 通用 Agent 循环不得 import 或硬编码技能内部选择器。
- 技能必须声明支持版本、前置条件、动作、验证、风险和降级。

## 安全

- 消息发送前验证唯一收件人和目标会话。
- 支付、验证码、密码和 `FLAG_SECURE` 页面立即停止。
- 外部副作用动作使用幂等键，失败后先观察副作用是否已发生。
- App 更新或选择器失效时安全停止，不能退回盲目坐标点击。

## 验证

- 至少使用两档屏幕尺寸和两个受支持 App 版本。
- Shizuku 和无障碍模式都要覆盖。
- 正常、空状态、登录、广告、网络失败和歧义场景必须测试。
- 新技能或版本变化同时更新 README、兼容矩阵、评测和 `HANDOFF`。
